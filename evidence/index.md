# Private Evidence Index

## Purpose

This index records evidence that is **retained privately** and therefore not
committed to the public repository. It exists so that the fellowship record can
refer to supporting material without publishing screenshots from authenticated
or redistribution-sensitive sources.

## Handling Rules

- Do not store the underlying private screenshot files in the public
  repository.
- Use stable evidence identifiers so repository documents and final reporting
  can refer to them consistently.
- Record enough metadata to understand the source, relevance, and publication
  constraints without needing the screenshot itself.

## Referencing Guidance

When citing privately retained evidence in repository documents or final
reporting:

- cite the evidence identifier
- summarize the reason it supports the analytical claim
- avoid reproducing protected portal material directly
- supplement with public scope descriptions where possible
